# サンプルデータ: セミナー受講アンケート

「生成AI活用入門」セミナーの受講者25人に，感想を自由記述してもらったという想定の架空データ．
一括タグ付け（`/batch`）を試したり，タグの意味の書き方で精度がどう変わるかを確かめたりするのに使う．

| ファイル | 内容 |
| --- | --- |
| `seminar_survey.csv` | アンケート本体．列は 回答者ID，年代，職種，受講形式（会場/オンライン），満足度（1〜5），感想 |
| `seminar_tags.json` | 推奨タグ定義（タグ名と意味） |
| `seminar_labels.csv` | 各回答に人手でタグを付けた正解ラベル（TRUE/FALSE） |

感想には，複数の話題を含む回答，肯定と否定が混ざった回答，空欄（R07），「特になし．」（R06），
具体的な話題を含まない感想（R14「めちゃくちゃ面白かったです！」），セル内改行を含む回答が入っている．
CSV は Excel で開けるよう BOM 付き UTF-8 で保存している．

## 使い方

1. `uv run hakari` で起動し，<http://127.0.0.1:8000/batch> を開く
2. `seminar_survey.csv` を選び，自由記述の列に「感想」を選ぶ
3. 下のタグ定義を入力して開始する（175回の問い合わせで，1分強かかる）
4. 結果 CSV の各タグ列を `seminar_labels.csv` と見比べる

## 推奨タグ定義

| タグ名 | 意味 |
| --- | --- |
| 内容 | セミナーで扱われた題材や事例，説明された内容について触れている（「〇〇の話が良かった」「内容が基礎的すぎた」なども含む） |
| 難易度 | 内容の難しさ・やさしさ，前提知識の要否，レベル感への言及 |
| 講師 | 講師の説明の分かりやすさ，話し方，熱意，質問への対応など，講師個人への言及 |
| 運営 | 時間配分・進行ペース・休憩，会場設備，オンライン配信の音声や映像，資料の配布，申込や事前案内など，運営面への言及 |
| 実践 | 学んだことを業務で使う意向や，使えるかどうかの見通しへの言及 |
| 要望 | 今後の開催や改善について，「〜してほしい」「〜があるとよい」など，具体的な要望・提案をはっきり述べている．感想や評価だけのものは含まない |
| 不満 | 何らかの不満や否定的な評価を述べている |

## 正解ラベルとの一致率（参考）

2026-10-04 に nimble（Bespoke-Nimble-9B，Q8_0）で測った値．

| タグ | 一致率 | 誤り |
| --- | --- | --- |
| 内容 | 25/25 | なし |
| 難易度 | 22/25 | R03，R04，R23 を見落とし |
| 講師 | 21/25 | R01，R14，R23 を誤って TRUE，R11 を見落とし |
| 運営 | 22/25 | R11 を誤って TRUE，R13，R16 を見落とし |
| 実践 | 23/25 | R15 を誤って TRUE，R21 を見落とし |
| 要望 | 22/25 | R05，R17，R21 を誤って TRUE |
| 不満 | 24/25 | R23 を見落とし |
| 全体 | 159/175（90.9%） | |

### 意味の書き方で精度が変わる例

最初は「内容」と「要望」を次のように定義していた．このときの全体の一致率は 147/175（84.0%）だった．

| タグ名 | 最初の意味 | 一致率 |
| --- | --- | --- |
| 内容 | 講義で扱ったテーマ・事例・題材そのものへの言及 | 15/25（正解 TRUE の11件中10件を見落とし） |
| 要望 | 今後の開催や改善についての要望・提案を含む | 20/25（要望の無い5件を誤って TRUE） |

抽象的な言い方だとモデルが「該当しない」に寄りやすく，具体的な言い回しの例を添えると拾えるようになった．
逆に「要望」は範囲を狭めて，「含まないもの」を書き足すと誤検出が減った．

ただし，推奨定義の例示はこのサンプルを見ながら書いたもので，サンプルに寄せすぎている面がある．
実際のアンケートでは，数十件を読んで正解を付け，同じように一致率を見ながら意味を調整するとよい．
